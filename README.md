# food-picture-01 — gourmet cheeseburger v2

A program that writes one picture of food to `/output/entry.png`: a
gourmet cheeseburger — glossy sesame brioche bun, melted cheddar
cheese dripping down a juicy seared beef patty, fresh lettuce and
tomato, steam rising, on a dark slate board with warm side lighting.
Generated with Google Gemini. The picture is bundled as `entry.png`;
`main.py` copies it byte-for-byte to the output directory and verifies
it is within the 1 MiB limit.

Run: `python3 main.py` (with `MAKEFUN_OUTPUT_DIR` set, else `/output`).
