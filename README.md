# food-picture-01 — steaming tonkotsu ramen

A program that writes one picture of food to `/output/entry.png`: a
steaming bowl of premium tonkotsu ramen — creamy golden broth, springy
noodles lifted with chopsticks, a jammy soft egg, glistening chashu,
scallions and chili oil, steam rising. The picture is bundled as
`entry.png`; `main.py` copies it byte-for-byte to the output directory
and verifies it is within the 1 MiB limit.

Run: `python3 main.py` (with `MAKEFUN_OUTPUT_DIR` set, else `/output`).
